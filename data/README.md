# Data reproducibility files

This directory does not redistribute the full MedHallu dataset.

- `selected_pair_ids.csv` contains the 100 `Pair_ID` values used in the manuscript.
- `sample_metadata.csv` contains the corresponding difficulty and hallucination-category metadata.

Use `notebooks/01_Dataset_Preparation.ipynb` with the official MedHallu distribution to reconstruct the methodological-validation cohort.
